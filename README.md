# 训练计划器 · 平板版

给销售现场用的版本：**可装到桌面、全屏、离线可用、触控尺寸放大**。

## 文件说明

| 文件 | 作用 |
|---|---|
| `index.html` | 主程序（功能与桌面版完全一致） |
| `manifest.webmanifest` | 让平板能"添加到主屏幕"，全屏打开 |
| `sw.js` | 离线缓存，装到主屏幕后没网也能用 |
| `icons/` | 桌面图标 |
| `局域网试机.bat` | 电脑上双击，用平板同 Wi-Fi 打开（临时试机用） |

## 一、装到平板的三种方式

### 方案 A · 托管上线，装成 App（推荐）

一次配置，之后**不依赖电脑、断网也能用**。

1. 电脑打开 <https://app.netlify.com/drop>（免费注册，登录后可用）
2. 把 **整个 `训练计划器-平板版` 文件夹**拖进页面
3. 得到一个 `https://xxxx.netlify.app` 的网址
4. iPad / 安卓平板用 **Safari / Chrome** 打开这个网址
5. 点 **分享 → 添加到主屏幕**（安卓 Chrome：菜单 → 添加到主屏幕）
6. 从桌面图标打开：全屏、无地址栏，第一次联网打开后即可离线使用

> 替代平台：GitHub Pages、Cloudflare Pages、Vercel，做法一样（上传整个文件夹）。
> 国内访问速度：Cloudflare Pages / Vercel 通常比 GitHub Pages 稳。

### 方案 B · 完全本地，不注册任何账号

1. iPad 装免费 App **「Documents」（Readdle）**
2. 把整个文件夹拷进去（微信文件传输 / iCloud 云盘 / AirDrop 都行）
3. 在 App 内点 `index.html` → 用内置浏览器打开

缺点：不是全屏，界面上下有 App 的工具栏。适合不想联网、也不想注册的情况。

### 方案 C · 局域网试机（临时）

1. 电脑和平板连**同一个 Wi-Fi**
2. 电脑上双击 `局域网试机.bat`（需要装过 Python）
3. 窗口里会显示 `IPv4 地址: 192.168.x.x`
4. 平板浏览器打开 `http://192.168.x.x:8080`

缺点：电脑必须开着。只适合试机，不适合每天带出去用。

## 二、现场使用流程（3 分钟）

1. 打开 App，**竖屏**拿着（表格会自动变成列表，比横屏更好读）
2. 边聊边填：性别、年龄、身高、体重 —— 30 秒
3. 问出**真实目标**，选「最想改善的部位」
4. 选「每周能训练几天」：**按客户实际能来的天数填，不要按理想天数填**
   （这是留存率影响最大的一个选项，填高了计划就废了）
5. 点「生成训练计划」
6. 从上往下讲，顺序就是说服顺序：
   - **身体数据** → 建立问题意识（"你不是胖，是肌肉太少"）
   - **每周日程** → 让他看见"一周只占两个晚上"
   - **今天练什么** → 具体到动作和组数，专业感来源
   - **怎么加重量** → 告诉他这不是一次性的事，是 8 周的事
7. 收口：点 **「复制文字版」** 发他微信；或点 **「打印」** → **存储为 PDF** 出纸
8. 换下一位客户：点 **「新客户」**

## 三、平板设置建议（很关键，别跳过）

| 设置 | 路径 | 为什么 |
|---|---|---|
| **关闭自动锁定** | 设置 → 显示与亮度 → 自动锁定 → 永不 | 讲解时屏幕不会黑 |
| **打开引导式访问** | 设置 → 辅助功能 → 引导式访问 → 打开 | 客户拿着看时不会误触退出、乱点。连按三次侧边键开启，再连按三次 + 密码关闭 |
| **调高亮度** | 控制中心 | 健身房灯光偏暗，60% 以下看不清 |
| **开勿扰模式** | 控制中心 → 专注 | 避免微信弹窗打断对话 |

## 四、数据与隐私

- 所有计算在浏览器本地完成，**没有任何上传**
- 平板版**不保存**上一位客户填的内容，每次打开都是默认值
  （避免把上一位客户的体重/年龄亮给下一位看）
- 需要给客户留档：**打印 → 存储为 PDF**，文件名写客户名字 + 日期
- 不需要客户留身高体重在设备里的话，讲完点「新客户」即可

## 五、常见问题

**Q：主屏幕图标点开是白屏？**
第一次要联网加载并缓存，等 3–5 秒或下拉刷新一次；之后就秒开。

**Q：改了内容怎么更新？**
重新上传部署即可。若平板没更新，把 `sw.js` 里 `CACHE = 'split-engine-v1'` 的版本号改成 `v2` 再部署一次，下次打开自动换新。

**Q：横屏还是竖屏？**
都行。竖屏更推荐——表格会自动变成"动作 + 组次 + 要点"的列表，字更大更好读。

**Q：能离线吗？**
方案 A 装到主屏幕后，只要成功打开过一次，之后断网也能用。

**Q：能同时存好几个客户的方案吗？**
当前版本不做保存（避免隐私串台）。需要的话告诉我，可以加"客户档案 + 本地保存"。
